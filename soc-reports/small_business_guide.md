# SOC Causal Correlation System - Guide for Small Businesses
## Non-Technical Overview (For Everyone)

### What is this system?
Imagine your business gets dozens or hundreds of security alerts every day from different security tools (antivirus, firewalls, email filters, etc.). Most of these alerts are noise - they look scary but aren't actually connected to real attacks. This system helps you:

1. **Group Related Alerts**: Instead of seeing 50 separate alerts, you see maybe 2-3 actual security incidents
2. **Find the Root Cause**: Tells you what likely started the problem (like a phishing email that led to everything else)
3. **Recommend Specific Actions**: Gives you clear, simple steps to fix the problem without overreacting

### Why Small Businesses Need This
- **Limited IT Staff**: You don't have a 24/7 security team to investigate every alert
- **Alert Fatigue**: Too many false alarms make you miss real threats
- **Resource Constraints**: You need to focus on what really matters
- **Cost Effective**: Helps prevent expensive breaches by catching issues early

### How It Works (Simple Analogy)
Think of security alerts like puzzle pieces scattered on a table:

**Before this system**: You see 100 puzzle pieces and don't know which ones belong together
**After this system**: The system groups pieces that fit together, shows you the picture they make, and tells you which piece is the corner piece (root cause)

### Key Benefits for Small Businesses
1. **Saves Time**: Reduces alert investigation from hours to minutes
2. **Reduces Stress**: Fewer false alarms means your team can focus on real threats
3. **Better Decisions**: Clear recommendations prevent overreactions or underreactions
4. **Learning Tool**: Helps your team understand attack patterns over time
5. **Cost Prevention**: Early detection prevents expensive data breaches

### What You Need to Get Started
1. **Basic Computer**: Any modern Windows/Mac/Linux computer
2. **Alert Data**: Export alerts from your existing security tools (most can export to text files)
3. **15 Minutes Setup**: Copy-paste alert data into the simple interface
4. **No Special Skills**: Designed for non-technical users

### How to Use It (Step-by-Step)
1. **Collect Alerts**: Export security alerts from your tools (antivirus, firewall, etc.) as text files
2. **Open the System**: Double-click the simple interface (looks like a basic form)
3. **Paste Alerts**: Copy and paste your alert text into the big text box
4. **Click Analyze**: Press the big blue button
5. **Read Results**: See grouped incidents, root cause, and simple action steps
6. **Take Action**: Follow the plain-English recommendations

### Example: What You'll See
**Input**: 10 security alerts from different times and tools
**Output**: 
- "Found 2 related incidents"
- "Incident #1: Likely started with a phishing email (alert_001)"
- "Confidence: 85%"
- "Recommended action: Disable the specific user session and force password reset"
- "Techniques detected: Phishing, Credential theft, Data transfer"

### Security Recommendations for Small Companies
#### Immediate Actions (Do These First)
1. **Enable Multi-Factor Authentication (MFA)** everywhere possible
2. **Keep Software Updated** - turn on automatic updates
3. **Backup Important Data** - use the 3-2-1 rule (3 copies, 2 different media, 1 offsite)
4. **Train Employees** - 15 minutes monthly on spotting phishing emails
5. **Use Strong Passwords** - consider a password manager (many free options)

#### Monthly Security Routine
1. **Review Alerts** - Run this system on your collected alerts once per week
2. **Check Backups** - Verify you can restore files from backup
3. **Update Passwords** - Change passwords for critical accounts
4. **Review Access** - Remove access for former employees or unused accounts

#### When You Get an Alert Recommendation
**Low Risk**: Monitor and log for more info
**Medium Risk**: Take specific action (like reset password for one user)
**High Risk**: Consider getting professional help or following incident response steps

### Understanding the Technical Terms (Simple Definitions)
- **Alert**: A notification from security software saying "something might be wrong"
- **Incident**: A group of related alerts that together indicate a real security issue
- **Root Cause**: The original problem that started everything else (like the first domino that fell)
- **Blast Radius**: How far the problem could spread (small = one user, medium = department, large = whole company)
- **Confidence**: How sure the system is about its analysis (like a weather forecast percentage)
- **Techniques**: Specific methods attackers use (has standard names like "phishing" or "malware")

### Cost Considerations
- **Free to Use**: This system is open source and free
- **Minimal Hardware**: Runs on most computers from the last 5 years
- **Time Investment**: ~15 minutes per week for most small businesses
- **Potential Savings**: Preventing one data breach can save thousands to millions

### Getting Help
If you're unsure about recommendations:
1. Start with the least disruptive action suggested
2. Document what you did and when
3. Consider consulting with a local IT professional for high-confidence, high-blast-radius incidents
4. Many communities have free or low-cost cybersecurity help for small businesses

### Remember: Perfect Security Isn't the Goal
The goal is to be secure enough that attackers move on to easier targets. This system helps you focus your limited time on the threats that actually matter.
